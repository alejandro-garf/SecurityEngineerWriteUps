## The Infinite Loop

Key concepts in modern DevOps practices:

- **CI/CD** — Deals with the frequent merging of code and adding testing in an automated manner to perform checks as new code is pushed and merged.
- **Infrastructure as Code (IaC)** — Allows us to reuse code used to deploy infrastructure (for example, cloud instances), which helps with consistent resource creation and management. It can also be used for configuration management.
- **Orchestration** — The automation of workflows.

**Question Answers:**
- **CI/CD** helps with the frequent merging of small code changes.
- **Monitoring** is the process of collecting data to analyse the performance of services.
- **IaC** is the third answer.

## Shifting Left

Shifting left means focusing on instilling security from the earliest stages of the development lifecycle. Adapting security testing to become flexible and integrated into the development lifecycle increases the chances of addressing issues promptly.

This approach to shifting left in DevOps is referred to as **DevSecOps**.

**Question Answers:**
- **Shift Left** is the term for implementing security at the earliest stages of the development lifecycle.
- **DevSecOps** is the term for doing this throughout the entire lifecycle.

## Security Strikes Back

DevSecOps relies heavily on automation and platform design that integrates security as a shared responsibility.

**Question Answers:**
- **Security silos** can lead to conflict.
- **Lack of visibility** is when we can't prioritise the right tasks at the right time.
- Needlessly overcomplicated security processes are called **astringent processes**.
